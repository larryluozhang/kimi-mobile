# Kimi Mobile (iOS)

iOS client for the Kimi Code web server (SwiftUI, iOS 17+). Feature parity with the Android/macOS clients.

## Build & deploy

- Xcode 15+; the project file is generated by XcodeGen: `xcodegen generate` (required after cloning or changing `project.yml`; fill in your own `DEVELOPMENT_TEAM` first)
- Simulator build: `xcodebuild -project KimiMobile.xcodeproj -scheme KimiMobile -destination 'generic/platform=iOS Simulator' build`
- Device deploy (free Apple ID / Personal Team signing, 7-day expiry):

```bash
./redeploy.sh   # archive + export + install to a connected device
```

On first launch, trust the developer certificate in Settings → General → VPN & Device Management. Re-run `redeploy.sh` before the 7-day expiry to renew.

## Voice input

Uses the system speech recognizer (`SFSpeechRecognizer`, see `SpeechInput.swift`); no bundled or downloadable offline model.

## Protocol notes

See `docs/PROTOCOL-NOTES.md` at the repository root. WS auth goes in the handshake header; prompts carry `model` + mode fields at the top level; phantom user messages are not rendered.
