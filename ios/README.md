# Kimi Mobile (iOS)

iOS client for the Kimi Code web server (SwiftUI, iOS 16+). Feature-parity with the Android/macOS versions.

## Build & Deploy

- Xcode 16.4 (installed on this machine from an external drive image at `/Volumes/Xcode`; **it must stay mounted during build/deploy**)
- The project file is generated by XcodeGen: `xcodegen generate` (if `.xcodeproj` is missing)
- Simulator build: `xcodebuild -project KimiMobile.xcodeproj -scheme KimiMobile -destination 'generic/platform=iOS Simulator' build`
- Device deploy (free Apple ID, Personal Team signing, expires in 7 days):

```bash
./redeploy.sh   # archive + export + install to the connected device
```

On first launch on the iPhone, trust the developer under Settings → General → VPN & Device Management. Re-run redeploy.sh to renew after the 7-day expiry.

## Protocol Highlights

Same as the Android README (see the Android repo for docs). WS auth rides in the handshake header; prompts carry model + mode fields at the top level; phantom user messages are not rendered.
